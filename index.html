Most of my side projects start the same way: a small daily annoyance, automated for good. It keeps me learning — and it keeps dinner interesting.

01

lazycoupon — the pizza bot

A fully autonomous app that books my daily discounted pizza: it clicks through a heavy JavaScript site using QA tooling, calls via a temporary phone number, and leaves my address. Started as a proof of concept for the simplest possible backend-to-frontend messaging. Ended as dinner. Watch it run ↗

02

ccpm — plugin manager for Claude Code

A fast terminal UI in Rust for browsing, installing and updating Claude Code plugins. Open source, 48★ and growing.

03

Summarizer — my news, in minutes

I wanted news as summaries sorted by what I actually care about, instead of an hour of scrolling. So I built it. The code is private — happy to walk through it on a call.

Twenty-five people,
one goal

For many months I led 25-person raids in World of Warcraft — recruiting, vetting, preparing strategy, coordinating the fight in real time, splitting the yield fairly, and keeping people glad to come back the next week. Everyone was a volunteer, so authority had to be earned. It's the most honest management training I've had, and it shows up in how I run projects.

Beyond code

After ten years in engineering, I spent nine months training in Gestalt therapy and earned the certificate. It wasn't a career change — it was an investment in the human half of the job: listening well, asking the right questions, and keeping collaboration honest. I live in Barcelona with my family, and I keep my work calm and predictable — for my clients and for myself.
