AI workflow automation, before it was fashionable

I automated my team's delivery workflow with LLM layers — GitLab tasks created, labeled and tracked; Slack posts written; pipelines followed — running as standalone binaries, half a year before MCP made this everyone's favorite topic. A full write-up is coming; the short version fits in a call.

ccpm — plugin manager for Claude Code

A fast terminal UI in Rust for browsing, installing and updating Claude Code plugins. My most-starred open-source project — written in a language I'd never claim on a CV, which is rather the point.

lazycoupon — the pizza bot

A fully autonomous agent that books my daily discounted pizza: it drives a heavy JavaScript site with QA tooling, calls the restaurant through a temporary phone number, and leaves my address. Autonomous browsing, telephony and a real-world result — built years before "agents" were a product category. Watch it run ↗

In-game economics — 32,000+ downloads

World of Warcraft developers told me a global database of in-game items didn't exist and couldn't be built. So I built the parser, shipped the database as CraftLib — a public library the community builds on — and proved it with LazyProf, which plans the cheapest path to level any profession. Together with a peer-to-peer guild auction house (lots, queues, voting), that's 32,000+ downloads of in-game finance tools — all in Lua, another language I never formally learned.
